CareerMate 설치 안내

쓰는 AI와 컴퓨터를 고르면 맞는 설치 방법 하나를 처음부터 단계별로 보여줍니다. Claude와 Codex는 터미널 없이 앱에서 설치할 수 있습니다.

내 PC의 파일과 명령을 다룰 수 있는 Codex·Claude 앱이 필요합니다. 웹이나 모바일 채팅에서는 설치할 수 없습니다. CareerMate는 npm에서 받을 수 있습니다.

1어떤 AI를 쓰고 있나요?

2어떤 컴퓨터를 쓰나요?

두 가지를 고르면 아래에 설치 방법이 나옵니다.

Claude 사용

Claude로 연결하기

Claude Desktop 앱 안에서 설치하는 방법과 터미널을 쓰는 방법이 있습니다. 대부분은 방법 1로 충분합니다.

방법 1: Claude Desktop 앱 Code 탭 추천

Claude Desktop 앱 안에서 작업 폴더를 열고 진행합니다. 별도 터미널이 필요 없습니다.

  1. 1

    Claude Desktop 앱 설치 후 로그인

    claude.ai/download에서 받아 설치하고 본인 계정으로 로그인하세요.

  2. 2

    Code 탭에서 빈 폴더 선택

    상단의 Code 탭을 누르고, 새 폴더 하나(예: 문서/CareerMate)를 작업 폴더로 고르세요.
    이 폴더가 CareerMate 작업실이 됩니다.

    Windows에서 "Git is required"가 뜰 때만 Git for Windows를 설치하고 Claude Desktop 앱을 다시 켜세요.

  3. 3

    아래 문장 붙여넣기

    Code 탭의 대화창에 붙여넣으세요. 터미널 명령이 아닙니다. AI는 공개 안내 페이지만 읽고 설치하며, 이력서와 개인정보는 외부로 올라가지 않습니다.

    https://careermate.life/llms-install.txt 를 읽고, 그 안내대로 CareerMate를 이 폴더에 설치하고 연결해줘. 데이터도 이 폴더의 .cm/data 안에 저장하고, Node 설치처럼 시스템에 바꿀 게 있으면 실행 전에 먼저 알려줘. 설치가 끝나면 앱 재시작 방법과 이력서를 주는 법, 대시보드 주소(http://127.0.0.1:4319)도 알려줘.

    Node는 미리 설치하지 않아도 됩니다. Claude가 먼저 확인하고, 없으면 설치를 도와줍니다. 설치 중에 허용 창이 뜨면 허용하세요.

  4. 4

    앱 재시작 후 연결 확인

    Claude Desktop 앱을 완전히 껐다 켜고(처음 한 번 MCP 승인 허용), "커리어메이트 연결됐는지 확인해줘"라고 말해 연결을 확인하세요.

    도구가 안 보이면? 앱을 트레이까지 완전히 종료했다 다시 켜고, 처음 뜬 승인 창을 허용했는지 확인하세요.

이력서 넣는 법: Code 탭 채팅에 파일을 첨부하는 게 가장 쉽습니다. 첨부가 안 되면 작업 폴더에 파일을 넣고 "이력서.pdf 읽어서 등록해줘"라고 하거나, 내용을 텍스트로 붙여넣으세요.
방법 2: Claude Code CLI 터미널에 익숙하다면

Claude를 터미널에서 직접 실행합니다. 터미널이 처음이면 방법 1을 쓰세요.

  1. 1

    Node.js 설치

    Windows: PowerShell에 붙여넣으세요.

    winget install OpenJS.NodeJS.LTS

    Mac: 터미널에 붙여넣으세요(Homebrew가 없으면 nodejs.org에서 LTS 설치).

    brew install node

    nodejs.org에서 설치 파일을 받아 더블클릭(계속 '다음')해도 됩니다. 터미널 여는 법은 아래 도움말을 참고하세요.

    Windows에서 Git for Windows는 CLI 필수 단계가 아닙니다. Bash 관련 오류가 날 때만 설치해도 됩니다.

  2. 2

    Claude Code 설치 후 로그인

    npm install -g @anthropic-ai/claude-code

    설치 후 claude를 실행하면 로그인 창이 열립니다(본인 Pro·Max 계정).

  3. 3

    빈 폴더에서 claude 실행 후 아래 문장 붙여넣기

    실행한 claude 안에 붙여넣으세요. 셸 명령이 아니고 AI에게 보내는 메시지입니다. AI는 공개 안내만 읽고 설치하며, 내 데이터는 외부로 올라가지 않습니다.

    https://careermate.life/llms-install.txt 를 읽고, 그 안내대로 CareerMate를 이 폴더에 설치하고 연결해줘. 데이터도 이 폴더의 .cm/data 안에 저장하고, Node 설치처럼 시스템에 바꿀 게 있으면 실행 전에 먼저 알려줘. 설치가 끝나면 앱 재시작 방법과 이력서를 주는 법, 대시보드 주소(http://127.0.0.1:4319)도 알려줘.

    설치 중 네트워크·허용을 물으면 한 번 허용하세요(npm 다운로드 때문).

  4. 4

    확인

    claude 안에서 /mcp를 입력해 careermate가 보이면 연결된 것입니다.

    안 보이면? node --version이 v22.5 이상인지, claude를 껐다 켰는지 확인하세요.

이력서 넣는 법: 파일 첨부가 가능하면 채팅에 바로 첨부하세요. 터미널에서 첨부가 어렵다면 작업 폴더에 파일을 넣고 "이력서.pdf 읽어서 등록해줘"라고 하면 됩니다.

기타 AI (Agent)

내 PC에서 명령을 실행하는 AI로 설치하기

Claude·ChatGPT가 아니어도, 내 컴퓨터에서 명령을 실행할 수 있는 AI 에이전트면 됩니다. 빈 폴더를 정하고 아래 문장을 그 AI의 대화창에 붙여넣으세요.

무료 모델이나 작은 모델은 한글 품질이 떨어지거나 사용량 제한에 걸릴 수 있습니다. Claude Pro나 ChatGPT Plus를 권장합니다. CareerMate 자체는 무료입니다.

  1. 1

    명령 실행 가능한 AI를 빈 폴더에서 열기

    내 컴퓨터에서 파일·명령을 다룰 수 있는 AI 에이전트(데스크톱 앱이든 CLI든)를 준비하고, 새 폴더 하나를 작업 폴더로 잡으세요.

  2. 2

    이 문장 붙여넣기

    그 AI의 대화창에 붙여넣으세요. 터미널 명령이 아닙니다. AI는 공개 안내만 읽고 설치하며, 내 데이터는 외부로 올라가지 않습니다.

    https://careermate.life/llms-install.txt 를 읽고, 그 안내대로 CareerMate를 이 폴더에 설치하고 연결해줘. 데이터도 이 폴더의 .cm/data 안에 저장하고, Node 설치처럼 시스템에 바꿀 게 있으면 실행 전에 먼저 알려줘. 설치가 끝나면 앱 재시작 방법과 이력서를 주는 법, 대시보드 주소(http://127.0.0.1:4319)도 알려줘.
  3. 3

    확인

    그 AI를 완전히 껐다 켜고(처음 한 번 승인을 물으면 허용), "커리어메이트 연결됐는지 확인해줘" 또는 /mcp로 확인하세요.

    안 보이면? node --version이 v22.5 이상인지, 앱을 완전히 껐다 켰는지 확인하세요.

이력서 넣는 법: 작업 폴더에 파일을 넣고 파일 이름이나 경로를 알려 주세요. 읽히지 않으면 내용을 텍스트로 붙여넣으세요.

도움이 더 필요하면

터미널(명령창) 여는 법 CLI를 쓸 때

터미널은 명령을 한 줄씩 입력해 실행하는 창입니다. 이렇게 엽니다:

  • Windows: 시작 버튼을 누르고 PowerShell을 검색해 Windows PowerShell을 실행합니다. 붙여넣기는 마우스 우클릭 또는 Ctrl+V, 실행은 Enter.
  • Mac: ⌘+Space로 스포트라이트를 열고 Terminal을 입력해 실행합니다. 붙여넣기는 ⌘+V, 실행은 Return.

명령 옆 [복사] 버튼을 누르고, 터미널에 붙여넣은 뒤 Enter를 누릅니다.

필요한 프로그램 받기 Node · Claude · Codex
  • Node.js (LTS): nodejs.org에서 설치 파일을 받아 더블클릭(계속 '다음'). 터미널·CLI 방법에 필요합니다.
  • Claude Desktop 앱: claude.ai/download. Code 탭에서 작업 폴더를 열 때 씁니다.
  • Codex 앱: developers.openai.com/codex/app. 작업 폴더를 열고 프롬프트를 붙여넣을 때 씁니다.
  • Git for Windows: git-scm.com/download/win. Windows에서 Claude Desktop 앱 Code 탭이 "Git is required"라고 막을 때만.

설치한 다음에는 위에서 고른 방법의 단계를 따르세요.

외부 저장소 연결 (선택)

PC 여러 대에서 같은 데이터를 쓸 때 켭니다. 연결한 폴더를 거쳐 PC끼리 동기화하며, 기본은 꺼져 있습니다.

개인정보 주의: 연결한 저장소에 모든 개인 데이터가 들어가니 GitHub 저장소는 비공개로 두고 드라이브 폴더는 공유하지 마세요. CareerMate 서버로는 아무것도 보내지 않습니다.
구글 드라이브 OneDrive·Dropbox·iCloud Drive도 같음
  • 첫 PC: 드라이브 안에 폴더를 만들고 대시보드 설정 > 외부 저장소 연결 > 폴더 연결에서 찾아보기로 고릅니다(경로를 직접 입력해도 됩니다).
  • 새 PC: CareerMate를 설치하고 같은 폴더를 연결하면 데이터가 들어옵니다.
GitHub 비공개 저장소 git을 쓴다면
  • 첫 PC: 비공개 저장소를 만들어 clone하고 그 폴더를 연결합니다. pull·commit·push는 CareerMate가 내 git 로그인으로 합니다.
  • 새 PC: CareerMate를 설치하고 같은 저장소를 clone해 연결하면 데이터가 들어옵니다.

두 PC에서 따로 고쳤으면 지금 PC의 내용이 남고, 다른 쪽은 백업에 보관되며 설정 화면에 경고가 뜹니다.
연결 해제를 누르면 꺼지고 폴더는 그대로 남습니다. 환경 변수 CAREERMATE_SYNC_DIR를 쓰면 설정보다 우선합니다(고급).

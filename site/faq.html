자주 묻는 질문

설치, 연결, 대시보드, 문서 읽기, 공고 찾기, 개인정보에서 자주 막히는 부분을 모았습니다. 설치가 처음이면 설치 안내부터 보세요.

시작하기 전에

돈이 드나요? API 키가 필요한가요?

CareerMate는 무료 MIT 라이선스 npm 패키지입니다. 안에 LLM이 없어서 API 키가 따로 필요 없습니다. 분석과 글쓰기는 이미 쓰고 있는 AI 구독(Claude 등)이 하고, CareerMate는 커리어 데이터를 내 PC에 저장했다가 AI에 넘겨 주는 "서랍장" 역할만 합니다. 배포본은 npm에서 확인할 수 있습니다.

어떻게 업데이트하나요?

AI에게 "CareerMate 업데이트해줘"라고 하면 최신 버전으로 올립니다(확인만 하려면 "최신이야?"). 업데이트 후에는 AI 앱 또는 MCP 연결을 재시작해 주세요.

설치 · 연결

MCP 도구가 안 보여요 (AI가 CareerMate를 모릅니다)

AI 클라이언트를 완전히 종료한 뒤 다시 시작했는지 확인하세요(설정만 바꾸고 재시작을 안 하면 적용되지 않습니다).

Claude Code는 첫 실행 시 프로젝트 서버에 대한 1회 승인을 묻습니다. 허용하세요. 클라이언트의 /mcp 명령으로 careermate 연결을 확인하거나, AI에게 "온보딩 상태 확인해줘"라고 해 응답이 오는지 보세요.

그래도 안 되면 클라이언트별 등록 방법을 설치 안내에서 확인하세요.

ChatGPT 웹/모바일, Gemini 웹에서 안 돼요

정상입니다. 이들은 클라우드에서 실행되어 원격 URL MCP만 쓸 수 있고, CareerMate는 사용자 컴퓨터에서 도는 로컬 stdio 서버라 연결할 수 없습니다.

로컬에서 실행되는 Claude Desktop, Claude Code, Codex CLI 중 하나를 사용하세요.

Node 버전 오류가 나요

CareerMate는 Node.js 22.5.0 이상이 필요합니다(node:sqlite 사용). node -v로 확인하고 필요하면 업데이트하세요.

대시보드

대시보드가 안 열려요 (http://127.0.0.1:4319)

그 주소는 CareerMate가 실행 중일 때만 열립니다. AI에게 "대시보드 열어줘"라고 하면 서버가 꺼져 있을 때도 백그라운드로 자동 시작한 뒤 브라우저를 엽니다.

포트가 이미 사용 중이면 자동으로 다른 포트를 씁니다(CAREERMATE_PORT로 고정 가능). 자동 시작이 실패하면 ~/.careermate/server.log를 확인하세요.

대시보드는 보안을 위해 127.0.0.1(이 컴퓨터)에서만 열립니다. 다른 기기에서는 접속할 수 없고, 의도한 동작입니다.

브라우저를 자동으로 안 열어요

첫 온보딩 때 한 번만 자동으로 엽니다. 이후에는 링크만 보여 줍니다. 직접 주소를 열거나, AI에게 "대시보드 열어줘"라고 하세요. 자동 열기를 끄려면 CAREERMATE_NO_OPEN=1.

문서(이력서·공고) 읽기

PDF가 안 읽혀요

스캔본/이미지 PDF(텍스트 레이어 없음)는 추출되지 않습니다. 이미지를 직접 볼 수 있는 AI라면 PDF를 그대로 보여주고, 아니면 내용을 텍스트로 붙여넣어 주세요.

암호로 보호된 PDF는 읽을 수 없습니다. 뷰어에서 암호를 해제해 다시 저장하거나 내용을 텍스트로 붙여넣으세요. 손상된 PDF, 25MB 초과 파일도 거부되며 안내 메시지에 이유가 나옵니다.

지원하는 파일 형식은?

PDF, Word(.docx), 한컴(.hwp/.hwpx), 텍스트(.txt/.md). 가능하면 절대 경로로 파일 위치를 알려 주세요(예: C:\Users\me\Desktop\이력서.pdf).

한글이 깨져요

UTF-8과 한국어 인코딩(CP949/EUC-KR)을 자동 감지합니다. 그래도 깨지면 파일을 UTF-8로 다시 저장하거나 내용을 붙여넣어 주세요.

공고 찾기

채용공고도 찾아주나요?

네. AI에게 "백엔드 공고 찾아줘", "경리 공고 찾아줘"처럼 말하면 원티드·점핏·리멤버·사람인의 공개 공고를 모아 보여줍니다. 로그인이나 API 키는 필요 없고, 밖으로 나가는 것은 검색어와 직무 조건뿐입니다(프로필·이력서는 보내지 않음). 잡코리아는 robots.txt 제약 때문에 넣지 않았습니다.

개발 직군만이 아니라 모든 직군에서 됩니다. 직무 이름을 각 사이트의 분류로 바꾸는 표가 내장돼 있습니다(리멤버 26개 그룹·315개 세부 직무, 사람인 21개 분야·2,178개 코드). 여러 사이트에 함께 올라온 공고는 한 줄로 합치고, 고른 공고만 저장해 적합도 분석과 자소서로 이어갑니다. 대시보드의 공고 찾기 화면에서도 같은 검색을 하고 클릭 한 번으로 저장할 수 있습니다.

오늘 올라온 공고만 볼 수 있나요?

자주 보는 직무를 검색 조건으로 한 번 저장해 두면 "오늘 올라온 내 직무 공고 보여줘"만으로 새 공고를 봅니다. 리멤버·사람인은 사이트 게시일로 거릅니다. 원티드·점핏은 게시일을 주지 않아 CareerMate가 처음 본 날로 거르므로, 첫 검색에서는 전부 새 공고로 보입니다.

경력 연차로 거를 수 있나요?

네. "경력 5년인데 프론트엔드 공고 찾아줘"처럼 연차를 말하면 경력 범위에 그 연차가 들어가는 공고만 남깁니다. 5년이면 "3~10년"은 남고 "8~20년"은 빠집니다. 경력 표기를 읽을 수 없는 공고는 빼지 않고 남겨 둡니다.

2026-11-04에 프론트엔드·경력 5년으로 검색했을 때 합친 뒤 173건 중 123건이 남고 50건이 연차 조건으로 빠졌습니다.

공고 분석 · 자소서

공고 URL은 어떻게 넣어요?

URL을 그대로 붙여넣어도 되고, 공고 본문 텍스트를 붙여넣어도 됩니다. CareerMate는 LLM이 없어 URL을 직접 크롤링하지 않으므로, 공고 본문 텍스트가 있으면 분석 품질이 가장 좋습니다.

분석이 안 되거나 결과가 비어 있어요

분석은 AI가 하고 CareerMate는 입력(프로필·공고)과 결과를 저장합니다. 먼저 프로필과 공고가 저장돼 있어야 합니다.

AI에게 "분석 전에 application context부터 불러와줘"라고 하면 프로필·이력서·공고를 한 번에 모아 분석 맥락을 갖춥니다.

면접 준비는 언제 만들 수 있나요

공고가 저장되어 있으면 AI에게 면접 준비를 요청해 저장할 수 있습니다. 지원 상태가 '서류 합격' 이상이 되면 대시보드가 면접 준비를 다음 할 일로 먼저 제안합니다.

이력서·자소서를 파일로 받을 수 있나요?

네. AI에게 "이력서 파일로 내보내줘"(또는 자소서/프로필)라고 하면 ~/.careermate/exports에 Markdown 또는 인쇄용 HTML(브라우저에서 "인쇄 → PDF로 저장")로 저장됩니다.

대시보드 문서·프로필 페이지에서 버튼으로 직접 다운로드할 수도 있습니다.

데이터 · 프라이버시

내 데이터는 어디에 저장되나요?

사용자 컴퓨터의 ~/.careermate(Windows: %USERPROFILE%\.careermate)에만 저장됩니다. 대시보드 설정 > 데이터 저장 위치에서 정확한 경로를 볼 수 있고, 기본 설정에서는 외부로 전송되지 않습니다.

저장 위치는 같은 화면의 폴더 변경으로 바꿀 수 있습니다(대시보드와 AI 앱을 다시 시작하면 적용). 직접 외부 저장소 연결을 켜면 고른 폴더로도 동기화되지만, CareerMate 서버로는 아무것도 보내지 않습니다.

회사가 탄탄한지도 알려주나요?

네. 공고를 저장하면 AI가 공시(매출, 영업이익, 부채비율), 국민연금 기준 인원과 최근 1년 입사·퇴사, 직원 평점, 뉴스를 조사해 S(매우 좋음)부터 D(위험)까지 등급을 매깁니다. 등급은 목록과 공고 찾기 결과의 회사 이름 옆에, 이유와 수치는 공고 상세에 나오고, 적합도 점수에는 섞지 않습니다.

PC 여러 대에서 쓰려면?

AI에게 "다른 PC에서도 쓰고 싶어, Google Drive로 연결해줘"(또는 "이 GitHub 주소로 연결해줘")라고 말하세요. 새 PC에서도 CareerMate를 업데이트하고 같은 말을 하면 됩니다. 대시보드 설정 > 외부 저장소 연결에서 구글 드라이브 같은 클라우드 폴더나 비공개 GitHub 저장소를 clone한 폴더를 직접 골라도 됩니다. 모든 개인 데이터가 그 저장소에 들어가니 저장소는 비공개로 두고 폴더는 공유하지 마세요.

두 PC에서 동시에 고치면?

자동으로 합치지 않습니다. 지금 PC의 내용이 남고, 다른 쪽은 백업에 보관되며 설정 화면에 경고가 뜹니다.

외부 저장소 연결을 끄려면?

설정 > 외부 저장소 연결에서 연결 해제를 누르거나 AI에게 연결을 끊어 달라고 하세요. 폴더는 그대로 남습니다.

백업하거나 전부 삭제하려면?

대시보드 설정 > 백업/내보내기에서 백업 생성·전체 JSON 내보내기를, 위험 구역에서 전체 초기화를 할 수 있습니다(초기화 직전 자동 백업).

여기서 해결되지 않으면 osntak@gmail.com으로 문의하세요. 문의에는 개인정보를 붙여넣지 마세요.

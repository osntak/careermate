로컬 MCP 취업 관리란?

이력서와 자소서를 웹서비스에 올려두는 대신, 내 컴퓨터에 저장한 데이터를 Claude·Codex 같은 AI가 필요한 순간 읽고 쓰게 만드는 방식입니다.

MCP는 AI가 도구를 쓰는 연결 규격입니다

MCP(Model Context Protocol)는 AI 앱이 외부 도구와 데이터를 일정한 방식으로 연결하도록 돕는 규격입니다. CareerMate는 공고, 이력서, 자기소개서, 지원 상태를 다루는 도구를 MCP로 제공합니다.

로컬이라는 말은 저장 위치를 뜻합니다

CareerMate의 데이터베이스와 대시보드는 사용자 컴퓨터에서 실행됩니다. 이력서 원문이나 지원 기록을 CareerMate 서버에 업로드하지 않습니다. 분석과 글쓰기는 사용자가 이미 쓰는 AI가 담당하고, CareerMate는 결과를 구조화해 로컬에 보관합니다.

일반 채팅과 무엇이 다른가요?

일반 채팅에서는 이전에 만든 자소서와 공고를 다시 붙여넣어야 하고 결과가 대화방에 흩어집니다. MCP 도구를 연결하면 AI가 저장된 공고와 경험을 조회하고, 새 분석 결과를 다시 같은 데이터베이스에 남길 수 있습니다.

어떤 작업을 연결할 수 있나요?

  • 이력서와 경험 등록
  • 채용공고 저장과 핵심 요구사항 분석
  • 공고별 적합도와 부족한 근거 확인
  • 자기소개서 버전 관리와 파일 내보내기
  • 지원 단계와 면접 준비 관리

누구에게 적합한가요?

Claude Code, Codex CLI, Gemini CLI, Cursor처럼 로컬 MCP 서버를 호출할 수 있는 AI 도구를 이미 쓰고 있고, 커리어 데이터를 한곳에 모아 두고 싶은 사람에게 적합합니다.

CareerMate는 무료입니다.

Node.js가 설치된 컴퓨터면 시작할 수 있고, 설치한 뒤에는 AI에게 말로 공고 저장과 자소서 관리를 시키면 됩니다.

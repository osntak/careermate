# 자주 묻는 질문 / 문제 해결 (FAQ & Troubleshooting)

설치·연결·사용 중 자주 막히는 지점을 모았습니다. 설치 자체가 처음이라면
[`../INSTALL.md`](../INSTALL.md)를, 연결 직후 무엇을 할지는
[`START_WORKFLOW.md`](START_WORKFLOW.md)를 먼저 보세요.

---

## 시작하기 전에

### 돈이 드나요? API 키가 필요한가요?
CareerMate 자체는 **무료·오픈소스**이고, 내부에 LLM이 없어 **별도 API 키가 필요 없습니다.**
분석·작성은 이미 쓰고 있는 AI 구독(Claude 등)이 그대로 수행하고, CareerMate는 커리어
데이터를 로컬에 저장·제공하는 "서랍장" 역할만 합니다.

### 어떻게 업데이트하나요?
AI에게 **"CareerMate 업데이트해줘"**(`update_careermate`)라고 하면 최신 버전으로 올립니다.
확인만 하려면 "최신이야?"(`check_for_update`). 업데이트 후에는 AI 앱 또는 MCP 연결을
**재시작**해 주세요.

## 설치 / 연결

### "MCP 도구가 안 보여요" / AI가 CareerMate를 모릅니다
1. AI 클라이언트를 **완전히 종료한 뒤 다시 시작**했는지 확인하세요(설정만 바꾸고 재시작을
   안 하면 적용되지 않습니다).
2. Claude Code는 첫 실행 시 프로젝트 서버에 대한 **1회 승인**을 묻습니다 — 승인하세요.
3. 클라이언트의 `/mcp` 명령으로 `careermate`가 연결됐는지 확인하거나, AI에게
   "온보딩 상태 확인해줘"라고 해 응답이 오는지 보세요.
4. 그래도 안 되면 클라이언트별 등록 방법을 [`../INSTALL.md`](../INSTALL.md)와
   [`SUPPORTED_AI_APPS.md`](SUPPORTED_AI_APPS.md)에서 확인하세요.

### ChatGPT 웹/모바일, Gemini 웹에서 안 돼요
정상입니다. 이들은 클라우드에서 실행되어 **원격 URL MCP만** 쓸 수 있고, CareerMate는
사용자 컴퓨터에서 도는 **로컬 stdio 서버**라 닿지 못합니다. 로컬에서 실행되는
**Claude Desktop · Claude Code · Codex CLI** 를 사용하세요(자세한 이유는
[`SUPPORTED_AI_APPS.md`](SUPPORTED_AI_APPS.md)).

### Node 버전 오류가 나요
CareerMate는 **Node.js 22.5.0 이상**이 필요합니다(`node:sqlite` 사용).
`node -v`로 확인하고 필요하면 업데이트하세요.

## 대시보드

### "대시보드가 안 열려요" (`http://127.0.0.1:4319`)
- 그 주소는 **CareerMate가 실행 중일 때만** 열립니다. AI에게 **"대시보드 열어줘"** 라고 하면
  서버가 꺼져 있을 때도 백그라운드로 자동 시작한 뒤 브라우저를 엽니다.
- **포트가 이미 사용 중**이면 자동으로 다른 포트로 폴백합니다. 환경변수
  `CAREERMATE_PORT`로 고정할 수 있습니다.
- 자동 시작이 실패하면 `~/.careermate/server.log`를 확인하세요.
- 대시보드는 보안상 **`127.0.0.1`(이 컴퓨터)** 에만 열립니다. 다른 기기에서는 접속되지
  않습니다(의도된 동작).

### 브라우저를 자동으로 안 열어요
첫 온보딩 때 한 번만 자동으로 엽니다. 이후에는 링크만 안내합니다 — 직접 주소를 열거나,
AI에게 "대시보드 열어줘"라고 하세요. 자동 열기를 끄려면 `CAREERMATE_NO_OPEN=1`.

## 문서(이력서·공고) 읽기

### "PDF가 안 읽혀요"
- **스캔본/이미지 PDF**(텍스트 레이어 없음)는 추출되지 않습니다. 이미지를 직접 볼 수 있는
  AI 클라이언트라면 PDF를 그대로 보여주고, 아니면 내용을 **텍스트로 붙여넣어** 주세요.
- **암호로 보호된 PDF**는 읽을 수 없습니다. 뷰어에서 암호를 해제해 다시 저장하거나 텍스트로
  붙여넣으세요.
- 손상된 PDF, 25MB가 넘는 파일도 거부됩니다 — 안내 메시지에 이유가 나옵니다.

### 지원하는 파일 형식은?
PDF, Word(`.docx`), 한컴(`.hwp`/`.hwpx`), 텍스트(`.txt`/`.md`). 가능하면 **절대 경로**로
파일 위치를 알려 주세요(예: `C:\Users\me\Desktop\이력서.pdf`).

### 한글이 깨져요
CareerMate는 UTF-8과 한국어 인코딩(CP949/EUC-KR)을 자동 감지합니다. 그래도 깨지면 파일을
UTF-8로 다시 저장하거나 내용을 붙여넣어 주세요.

## 공고 찾기

### 채용공고도 찾아주나요?
네. AI에게 "백엔드 공고 찾아줘", "경리 공고 찾아줘"처럼 말하면 **원티드·점핏·리멤버·사람인**의
공개 공고를 모아 보여줍니다. 로그인이나 API 키는 필요 없고, 밖으로 나가는 것은 검색어와 직무
조건뿐입니다(프로필·이력서는 보내지 않음). 잡코리아는 robots.txt 제약 때문에 넣지 않았습니다.
개발 직군만이 아니라 모든 직군에서 됩니다. 직무 이름을 각 사이트의 분류로 바꾸는 표가 내장돼
있습니다(리멤버 26개 그룹·315개 세부 직무, 사람인 21개 분야·2,178개 코드). 여러 사이트에 함께
올라온 공고는 한 줄로 합칩니다. 고른 공고만 저장되고, 저장한 공고는 적합도 분석과 자소서로 이어집니다.
대시보드의 **공고 찾기** 화면에서도 같은 검색을 하고 클릭 한 번으로 저장할 수 있습니다.

### 오늘 올라온 공고만 볼 수 있나요?
자주 보는 직무를 검색 조건으로 한 번 저장해 두면 **"오늘 올라온 내 직무 공고 보여줘"** 만으로
새 공고를 봅니다. 리멤버·사람인은 사이트 게시일로 거릅니다. 원티드·점핏은 게시일을 주지 않아
CareerMate가 처음 본 날로 거르므로, **첫 검색에서는 전부 새 공고로 보입니다.**

### 경력 연차로 거를 수 있나요?
네. "경력 5년인데 프론트엔드 공고 찾아줘"처럼 연차를 말하면 경력 범위에 그 연차가 들어가는 공고만
남깁니다. 5년이면 "3~10년"은 남고 "8~20년"은 빠집니다. 경력 표기를 읽을 수 없는 공고는 빼지 않고
남겨 둡니다. 2026-11-04에 프론트엔드·경력 5년으로 검색했을 때 합친 뒤 173건 중 123건이 남고
50건이 연차 조건으로 빠졌습니다.

## 공고 분석 / 자소서

### "공고 URL은 어떻게 넣어요?"
URL을 그대로 붙여넣어도 되고, 공고 **본문 텍스트**를 붙여넣어도 됩니다. CareerMate는 LLM이
없어 URL을 직접 크롤링하지 않으므로, **공고 본문 텍스트가 있으면 분석 품질이 가장 좋습니다.**
AI에게 "이 공고 저장하고 분석해줘"라고 하면서 URL이나 본문을 함께 주세요.

### 회사가 탄탄한지도 알려주나요?
네. 공고를 저장하면 AI가 공시(매출·영업이익·부채비율), 국민연금 기준 인원과 최근 1년 입사·퇴사, 직원 평점, 뉴스를
조사해 S(매우 좋음), A(좋음), B(보통), C(주의), D(위험) 중 하나로 매깁니다. 확인한 정보가 모자라면 "정보 부족"으로 둡니다.
등급은 공고 목록과 공고 찾기 결과의 회사 이름 옆에, 이유와 수치는 공고 상세에 나옵니다. 적합도 점수에는 섞지 않습니다.
조사는 AI의 웹 검색으로 하므로, 웹을 볼 수 없는 AI 앱에서는 비어 있을 수 있습니다. 그럴 땐 "이 회사 상태 조사해줘"라고 다시 부탁하세요.

### "분석이 안 돼요" / 결과가 비어요
- 분석은 **AI가** 수행하고 CareerMate는 입력(프로필·공고)과 결과를 저장합니다. 먼저
  **프로필과 공고가 저장돼 있어야** 합니다.
- AI에게 "분석 전에 application context부터 불러와줘"라고 하면 프로필·이력서·공고를 한 번에
  모아 분석 맥락을 갖춥니다.

### 면접 준비는 언제 만들 수 있나요
공고가 저장되어 있으면 AI에게 면접 준비를 요청해 저장할 수 있습니다. 다만 지원 상태가
**'서류 합격(document_passed)' 이상**이 되면 대시보드가 면접 준비를 다음 행동으로 더 적극적으로 제안합니다.

### 이력서·자소서를 파일로 받을 수 있나요?
네. AI에게 **"이력서 파일로 내보내줘"**(또는 자소서/프로필)라고 하면
`~/.careermate/exports`에 **Markdown** 또는 **인쇄용 HTML**(브라우저에서 "인쇄 → PDF로 저장")로
저장됩니다(`export_resume`/`export_profile`/`export_cover_letter`). 대시보드 **문서·프로필
페이지**에서 버튼으로 직접 다운로드할 수도 있습니다.

## 데이터 / 프라이버시

### 내 데이터는 어디에 저장되나요?
사용자 컴퓨터의 `~/.careermate`(Windows: `%USERPROFILE%\.careermate`)에만 저장됩니다.
대시보드 **설정 > 데이터 저장 위치**에서 경로를 보고 **폴더 변경**으로 옮길 수 있습니다. CareerMate가
외부 서버로 개인 데이터를 보내는 일은 없습니다(외부 호출은 선택적 버전 확인과 공고
검색 시 검색 키워드·직무 조건뿐). 외부 저장소를 연결한 경우에만 그곳에 사본이 생깁니다.

### AI와 대화하면 내 데이터는 어디로 가나요?
CareerMate 도구의 응답(프로필·이력서·자소서 등)은 **당신이 연결한 AI 클라이언트**
(Claude·Codex 등)에 전달되어 그 AI가 분석·작성에 사용합니다 — 그 데이터의 처리에는
**해당 AI 서비스의 개인정보 정책**이 적용됩니다. CareerMate 자체는 그 어떤 서버로도
데이터를 보내지 않지만, "AI에게 보여준 내용"은 그 AI 서비스로 간다는 점은 알아두세요.
민감한 항목은 저장하지 않거나, AI 서비스의 학습 제외(opt-out) 설정을 확인하면 됩니다.

### 백업하거나 전부 삭제하려면?
대시보드 **설정 > 백업 / 내보내기**에서 백업 생성·전체 JSON 내보내기를, **위험 구역**에서
전체 초기화를 할 수 있습니다(초기화 직전 자동 백업). **주의:** 초기화해도 자동 백업 파일은
데이터 폴더의 `backups/`에 남습니다 — PC 양도 등으로 흔적 없이 지우려면 초기화 후
`~/.careermate` 폴더 자체(또는 그 안의 `backups/`)를 직접 삭제하세요. 외부 저장소를 연결한
적이 있다면 그 폴더(또는 GitHub 저장소)도 따로 지워야 합니다.

### PC 여러 대에서 쓰려면?
AI에게 "다른 PC에서도 쓰고 싶어, Google Drive로 연결해줘"(또는 "이 GitHub 주소로 연결해줘")라고
말하세요. 다른 PC에서도 CareerMate를 업데이트하고 같은 말을 하면 됩니다. 대시보드
**설정 > 외부 저장소 연결**에서 Google Drive 같은 폴더나 비공개 GitHub 저장소를 clone한 폴더를
직접 연결해도 됩니다. 개인 데이터 전부가 그곳에
들어가니 저장소는 비공개로, Drive 폴더는 공유하지 마세요. 순서는
[`../INSTALL.md`](../INSTALL.md#외부-저장소-연결-pc-여러-대에서-쓰기)에 있습니다.

### 두 PC에서 따로 고치면 어떻게 되나요?
자동으로 합치지 않습니다. 지금 PC의 데이터가 남고 다른 PC 버전은
`backups/sync-conflict-<시각>/`에 보관되며, 설정 화면에 경고가 뜹니다.

### 외부 저장소 연결을 끄려면?
대시보드 **설정 > 외부 저장소 연결**에서 **연결 해제**를 누르거나 AI에게 연결을 끊어 달라고 하세요. 외부 저장소 폴더는 그대로 남습니다.
